# 🔵 Reserva de Turnos: La Mesa del Cliente

Be gestiona la reserva de turnos de forma eficiente, consumiendo únicamente los recursos habilitados por el prestador.

---

## 1. Descubrimiento Inteligente
Be solo muestra recursos que tengan el flag `estaHabilitado` activo en Room. Esto garantiza que el cliente nunca intente reservar un espacio "apagado" por el profesional.

## 2. Consumo de Disponibilidad
La App Azul recibe los bloques de tiempo procesados, permitiendo una selección fluida sin lag computacional.
